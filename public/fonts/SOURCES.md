# Polices locales

Ressources WOFF2 officielles récupérées le 18 novembre 2026 via [Google Fonts CSS API](https://developers.google.com/fonts/docs/css2), pour les familles et graisses déjà utilisées par Guépard : DM Sans 400–700, Kalam 400/700 et Nunito 700–1000. Les sous-ensembles latin et latin étendu sont conservés pour le français et l’anglais. Les fichiers sont servis localement avec font-display: swap ; aucun appel Google Fonts n’est requis par les visiteurs.

Sources et licences SIL Open Font License 1.1 :

- [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans) : dmsans-OFL.txt
- [Kalam](https://github.com/google/fonts/tree/main/ofl/kalam) : kalam-OFL.txt
- [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito) : nunito-OFL.txt

Les définitions locales et leurs plages Unicode sont dans src/fonts.css. Les fichiers n’ont pas été modifiés.
